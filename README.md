# MedPredict-AI
Pneumonia Detection Deep Learning Model

## Datasets Used
This project combines two major datasets to ensure high accuracy and diversity:

1. **Primary Dataset (Chest X-Ray Images):**
   - Source: [Kaggle]
   - Link: [https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia]
   
2. **Secondary Dataset (COVID-19 Radiography Database):**
   - Source: [Kaggle]
   - Link: [https://www.kaggle.com/datasets/tawsifurrahman/covid19-radiography-database]

> **Note:** These datasets were merged and pre-processed to create a balanced collection of 15,835 images.
